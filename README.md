## Project Overview

Sweet Rise Bakery is a bakery website created to provide customers with information about the bakery and its products.

The website is designed to give visitors a simple and clear way to learn about Sweet Rise Bakery, view the products available, make an enquiry and find the bakery's contact information.

The website includes five main pages:

- Home
- About Us
- Products
- Enquiry
- Contact

The website is being developed in stages. Part 1 focuses on creating the HTML structure and content of the website. CSS and JavaScript will be added in the later parts of the project.

---

## Website Goals and Objectives

The main goals of the Sweet Rise Bakery website are:

- To introduce customers to Sweet Rise Bakery.
- To provide information about the bakery and what it offers.
- To display the different products available.
- To allow customers to submit enquiries.
- To provide customers with contact information.
- To create a simple and easy-to-navigate website.
- To provide a clear foundation for adding CSS and JavaScript in later parts of the project.

---

## Key Features and Functionality

The website contains the following features:

### Home Page
- Introduces Sweet Rise Bakery.
- Provides a welcome message.
- Gives visitors an overview of the bakery.

### About Us Page
- Explains what Sweet Rise Bakery is about.
- Provides information about the bakery's values.
- Describes the bakery's commitment to its customers.

### Products Page
The Products page introduces the different categories of baked goods offered by Sweet Rise Bakery, including:

- Bread
- Buns and Rolls
- Cakes
- Pastries
- Confectionery

### Enquiry Page
The Enquiry page contains a form where customers can provide:

- Full name
- Email address
- Phone number
- Enquiry type
- Message

### Contact Page
The Contact page provides:

- Telephone number
- Email address
- Physical address
- Business hours
- A link to the Enquiry page

### Navigation
All five pages contain a navigation menu that allows users to move between the different pages of the website.

## Part 1 Details

Part 1 focuses on creating the basic structure of the Sweet Rise Bakery website using HTML.

The following HTML pages have been created:

- `index.html`
- `about.html`
- `products.html`
- `enquiry.html`
- `contact.html`

The website uses HTML elements such as:

- `<header>`
- `<main>`
- `<section>`
- `<h1>` and `<h2>`
- `<p>`
- `<ul>` and `<li>`
- `<form>`
- `<label>`
- `<input>`
- `<select>`
- `<textarea>`
- `<button>`
- `<footer>`

The pages are connected using HTML navigation links.

CSS and JavaScript are not included in Part 1 because they will be completed during the later stages of the project.
